# شات كيمت

تطبيق دردشة ويب (PWA) بروح فرعونية — بيشتغل على الآيفون من Safari ويتضاف للشاشة الرئيسية.

🔗 **اللينك:** https://kimoamr2027-cloud.github.io/chat-kemet/

## اللي موجود دلوقتي (واجهة كاملة ببيانات تجريبية)
متبني على الديزين المعتمد في فولدر `design/`:
- تسجيل الدخول (الاسم + النوع + جوجل شكل بس)
- غرف الدردشة: بحث، تابات (الكل / الأكثر نشاطًا / غرفي)
- محادثة الغرفة: ردود، تفاعلات، ستيكرات، فويس (تجريبي)، بيكتب...، الأعضاء والمشرفين (كتم/طرد)
- الرسائل الخاصة + المحادثة الخاصة: علامات القراءة، كتم، حظر، إبلاغ
- الإشعارات، بياناتي (صورة + صور + بيانات)، الإعدادات (منها الوضع الليلي)
- نشر أوتوماتيك على GitHub Pages مع كل تعديل على `main`

كل حاجة لسه على الجهاز بس — مفيش سيرفر.

## الجاي
- ربط Firebase: تسجيل دخول بجوجل، Firestore للرسايل، Storage للصور والفويس
