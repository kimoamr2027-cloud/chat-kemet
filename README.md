# شات كيمت

تطبيق دردشة ويب (PWA) بروح فرعونية — بيشتغل على الآيفون من Safari ويتضاف للشاشة الرئيسية.

🔗 **اللينك:** https://kimoamr2027-cloud.github.io/chat-kemet/

## اللي موجود دلوقتي (واجهة كاملة ببيانات تجريبية)
متبني على الديزين المعتمد في فولدر `design/`:
- تسجيل الدخول (الاسم + النوع + جوجل شكل بس)
- غرف الدردشة: بحث، تابات (الكل / الأكثر نشاطًا / غرفي)
- محادثة الغرفة: ردود، تفاعلات، ستيكرات، فويس (تجريبي)، بيكتب...، الأعضاء والمشرفين (كتم/طرد)
- الرسائل الخاصة + المحادثة الخاصة: علامات القراءة، كتم، حظر، إبلاغ
- الإشعارات، بياناتي (صورة + صور + بيانات)، الإعدادات (منها الوضع الليلي)
- نشر أوتوماتيك على GitHub Pages مع كل تعديل على `main`

## Firebase (المرحلة التانية)
- تسجيل الدخول بجوجل (Firebase Auth)
- بيانات الأعضاء في `users/{uid}` (الاسم، النوع، النبذة، المدينة، السن)
- الغرف في `rooms/{roomId}` والرسايل في `rooms/{roomId}/messages` — بتظهر لحظيًا
- قواعد الأمان في `firestore.rules` (بتتحط في Firebase Console ← Firestore ← Rules)
- بيانات المشروع في `src/firebase-config.js`

## المرحلة التالتة
- الرسائل الخاصة الحقيقية في `chats/{uid1_uid2}` + `messages` — مع علامة القراءة وعداد غير المقروء
- إعدادات الخصوصية السرية في `settings/{uid}`: المحظورين، ومين يقدر يبعتلك، وعلامة القراءة
- البلاغات في `reports` — بتتراجع من Firebase Console بس
- الغرف اللي العضو دخلها في `users/{uid}.rooms`

## الإشعارات (جوه التطبيق)
- `notifications/{uid}/items`: رد، ذكر بـ @، تفاعل، رسالة خاصة
- القواعد بتتأكد إن كل إشعار وراه رسالة حقيقية، وبتحترم الحظر وإعدادات الإشعارات
- شريط بيظهر فوق + نقطة على الجرس + عداد على الرسائل

لسه: إشعارات شاشة القفل (Push) — محتاجة Cloud Functions وخطة Blaze، والصور والفويس.

## الجاي
- ربط Firebase: تسجيل دخول بجوجل، Firestore للرسايل، Storage للصور والفويس
