# رفع شات كيمت على جوجل بلاي — دليل خطوة بخطوة

كل الصور اللي هتحتاجها في الفولدر ده (`store/`):

| الملف | مكانه في Play Console |
|---|---|
| `icon-512.png` | أيقونة التطبيق (512×512) |
| `feature-1024x500.png` | صورة الميزة / الغلاف (1024×500) |
| `phone-1-rooms.png` … `phone-5-honor.png` | لقطات شاشة الموبايل (من ٢ لـ ٨ صور) |

ملف التطبيق نفسه: **`chat-kemet-play.aab`** — بتلاقيه في GitHub ← Releases ← آخر نسخة «شات كيمت للأندرويد».
(ملف `chat-kemet.apk` ده للموقع بس، **ماترفعوش** على جوجل بلاي.)

---

## ١. حساب المطوّر
1. ادخل https://play.google.com/console وسجّل بحساب جوجل.
2. اختار **حساب شخصي (Personal)**، وادفع **٢٥ دولار مرة واحدة**، وكمّل التحقق من البطاقة الشخصية.
3. اكتب إيميل للتواصل (هيظهر للناس في صفحة التطبيق).

## ٢. إنشاء التطبيق (Create app)
- **App name:** `شات كيمت - دردشة مصرية`
- **Default language:** العربية – ar
- **App or game:** App
- **Free or paid:** Free
- وافق على الشروط ← Create app

## ٥. الاختبار المقفول (Closed testing) — ١٢ شخص × ١٤ يوم
1. Testing ← **Closed testing** ← Create track.
2. **Testers:** اعمل قايمة إيميلات (Gmail) لـ **١٥–٢٠ شخص** من أعضاء الشات.
3. Create release ← ارفع **`chat-kemet-play.aab`** ← اكتب في Release notes: `أول نسخة من شات كيمت`.
4. Countries: Egypt (وأي دول تانية).
5. ابعت للمختبرين **لينك الاشتراك (Join on the web)** — كل واحد يدوس عليه ويسطّب التطبيق **من جوجل بلاي** ويفضل مسطّبه ١٤ يوم.
6. بعد ١٤ يوم: Dashboard ← **Apply for production** وجاوب الأسئلة.

## ٦. ⚠️ مهم بعد أول رفع — بصمة جوجل
جوجل بيوقّع التطبيق بمفتاح بتاعه، وعلشان التطبيق يفتح **من غير شريط اللينك اللي فوق** لازم بصمته تتضاف للموقع:

1. Play Console ← **Test and release ← App integrity ← App signing**.
2. انسخ **SHA-256 certificate fingerprint** اللي تحت **App signing key certificate**
   (شكله كده: `AB:CD:12:...` — ٣٢ جزء).
3. ابعتهولي، وأنا أضيفه في الموقع.

## ٧. لما تنزّل تحديث بعد كده
كل ما يحصل تغيير في فولدر `android/` بيتعمل ملف `chat-kemet-play.aab` جديد في GitHub Releases برقم نسخة أكبر — ارفعه في نفس المكان (Closed testing أو Production ← Create new release).
تحديثات الشات نفسه (الغرف والميزات) **مش محتاجة تحديث على جوجل بلاي** — بتوصل لوحدها لأن التطبيق بيفتح الموقع.
